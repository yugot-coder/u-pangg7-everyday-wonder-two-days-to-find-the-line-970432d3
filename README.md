One sentence, up to 200 characters, on a small moment of wonder in everyday life, judged pairwise by an AI judge that rewards surprise.

> On rainy mornings my houseplant leans away from the window and toward me, as if the sun had called in sick and I would have to be the light instead.

## Run it

```sh
python3 main.py
```

Writes the line to `<MAKEFUN_OUTPUT_DIR>/entry.txt` (default `/output/entry.txt`). Standard library only, deterministic, no network. The program validates the line's length (1–200 characters) and reads the file back, failing loudly if what landed on disk differs from the line it meant to write.
